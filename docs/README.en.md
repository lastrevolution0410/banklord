## Terms

| Term | Meaning |
|---|---|
| **Addon** | The part of Banklord in game. Shows stock and orders, scans the guild bank, has the buttons for bank managers. |
| **Companion** | Small program on your PC. Carries data back and forth between addon and website. Runs in the background, controlled in the browser. |
| **Updater** | Keeps addon and Companion up to date automatically. Runs invisibly in the background. |
| **Setup** | The installer you download from the website. |
| **Website** | Your guild's Banklord site. Catalog, cart, orders, administration. |
| **Scan** | The addon reads the guild bank's contents when a manager opens it. |
| **`/reload`** | In-game command. Only then (or after logging out) does WoW save what the addon knows, so the Companion can read it. |
