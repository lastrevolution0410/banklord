## Begriffe

| Begriff | Bedeutung |
|---|---|
| **Addon** | Der Teil von Banklord im Spiel. Zeigt Bestand und Bestellungen, scannt die Gildenbank, hat die Knöpfe für Bankverwalter. |
| **Companion** | Kleines Programm auf dem PC. Bringt Daten zwischen Addon und Website hin und her. Läuft im Hintergrund, Bedienung im Browser. |
| **Updater** | Hält Addon und Companion automatisch aktuell. Läuft unsichtbar im Hintergrund. |
| **Setup** | Das Installationsprogramm, das du von der Website lädst. |
| **Website** | Die Banklord-Seite deiner Gilde. Katalog, Warenkorb, Bestellungen, Verwaltung. |
| **Scan** | Das Addon liest den Inhalt der Gildenbank, wenn ein Verwalter sie öffnet. |
| **`/reload`** | Befehl im Spiel. Erst danach (oder nach dem Ausloggen) speichert WoW, was das Addon weiß, und der Companion kann es lesen. |
