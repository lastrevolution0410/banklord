# Sicherheitslücken melden / Reporting security issues

**Bitte keine öffentlichen Issues für Sicherheitsprobleme.**
**Please do not open public issues for security problems.**

Melde sie vertraulich über GitHub: Reiter **Security** → **Report a vulnerability**.
Report them privately on GitHub: **Security** tab → **Report a vulnerability**.

Hilfreich sind / Helpful:

- betroffener Teil (Addon, Website, Companion, Updater, Setup) und Version
- Schritte zum Nachvollziehen
- mögliche Auswirkungen

Du bekommst in der Regel innerhalb von 7 Tagen eine Antwort. Bitte veröffentliche Details erst, wenn ein Update verfügbar ist.
You will usually get an answer within 7 days. Please wait for a fix before publishing details.

Unterstützt wird jeweils nur die neueste Version. / Only the latest release is supported.
