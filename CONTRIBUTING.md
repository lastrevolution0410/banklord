# Contributing

Thanks for helping. Issues and pull requests are welcome, in English or German.

- **Bugs:** Include your game version, the addon version (`/banklord`), the website version (footer) and the steps to reproduce. Never post tokens, connect codes or passwords.
- **Security problems:** Don't open a public issue. Report them privately through GitHub's *Report a vulnerability* button.
- **Code:** Run `sh dev/run-tests.sh` before opening a pull request. Keep changes focused and add a test when you fix a bug.

- **Artwork:** Only original work or work under a compatible license. No assets ripped from the game client.
